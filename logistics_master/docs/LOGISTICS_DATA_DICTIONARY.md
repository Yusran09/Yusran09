# Logistics Data Dictionary

_Generated by the ETL (version 1.0.0) from `etl/lpl/schema.py` - do not edit by hand._

Types are portable between SQLite and PostgreSQL (`TEXT`, `INTEGER`, `DOUBLE PRECISION`, `DATE`, `TIMESTAMP`). Dates are ISO-8601 text in SQLite. Flags are `INTEGER` 0/1.

Layers: **REFERENCE** (lookups) · **LINEAGE** (source register) · **RAW** (unmodified staging rows) · **ANALYTICS** (logistics readiness) · **CORE** (normalised master data) · **CONTROL** (mapping exceptions, checks, change log, history).
